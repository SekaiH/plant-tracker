# 🌿 批次匯入收藏清單 — 使用說明

這份工具會把你提供的整份清單(香草、花卉、蔬菜、多肉、觀葉、蕨類與苔蘚、
鹿角蕨,共 **240 株植物**,以及工具設備跟堆肥系統資源共 **23 項**)一次匯入
到植況簿系統裡,不用一筆一筆手動輸入。

## 這是怎麼運作的

`scripts/import-collection.js` 這支腳本會:
1. 自動登入你的植況簿後端(跟你平常在網頁上登入是同一組帳密)
2. 逐筆呼叫系統既有的「新增植物」「新增工具」API,效果跟你自己在畫面上
   一筆一筆手動新增完全一樣,只是自動化跑過一輪
3. **完全沒有改動任何資料庫結構,不需要跑 migration**

## 資料怎麼對應的(讓你知道匯入後長什麼樣子)

### 植物類(香草/花卉/蔬菜/多肉/觀葉/蕨類苔蘚/鹿角蕨)

| 系統欄位 | 對應內容 |
| --- | --- |
| 名稱 | 品種名稱(鹿角蕨保留完整學名/品系標記,如「爪哇 P. willinckii」) |
| 分類 | 依你原本的分類分組:香草/花卉/蔬菜/多肉/觀葉/蕨類與苔蘚/鹿角蕨 |
| 品種欄位 | 規格/盆器資訊(如「5寸盆×1」),鹿角蕨則放 willinckii/veitchii/hybrid 等分類 |
| 進價成本 | 價格(0 元的維持 0,如自插、自撿、贈品等) |
| 備註 | 來源(代號已展開成全名,如「丁」→「丁（旋轉花市）」)、親本(鹿角蕨的雜交組合)、原始備註全部併入 |
| 狀態 | 鹿角蕨依你標註的「穩定/已死/急救中/狀況差」對應到「成株/死亡/狀況不佳」;其餘類別預設成株,幼苗/小苗類的花卉設為幼苗 |

### 工具設備類

`工具設備` 表格 13 項直接對應進去;`堆肥與資產系統資源` 那 10 項(堆肥箱本身、
純露機、廚餘機、木碎塊等)因為性質上是「耐久資源」不是消耗性堆肥材料,
也一併放進工具設備清單管理,備註欄保留原本的狀態/用途說明。

## 怎麼執行

### 第一步:確認後端已經啟動

跟平常一樣,開一個終端機:
```
cd plant-tracker-backend
npm run dev
```
確認看到 `http://localhost:4000` 的訊息,這個視窗留著別關。

### 第二步:另開一個新的終端機,執行匯入腳本

```
cd scripts
node import-collection.js
```

如果你的帳密不是預設的 `owner` / `changeme123`,要加上環境變數:

**Windows(命令提示字元):**
```cmd
set PT_USERNAME=你的帳號
set PT_PASSWORD=你的密碼
node import-collection.js
```

**Windows(PowerShell):**
```powershell
$env:PT_USERNAME="你的帳號"
$env:PT_PASSWORD="你的密碼"
node import-collection.js
```

### 第三步:看結果

跑完會印出類似這樣的統計:
```
========================================
匯入全部完成
植物: 240/240 成功
工具/資源: 23/23 成功
========================================
```

如果有失敗項目,會列出失敗的名稱跟原因,常見狀況：
- 網路不穩或後端剛好卡住 → 重新執行一次即可(已經成功匯入的不會重複,
  只是會多出一筆同名的,需要手動比對刪除重複的,見下方提醒)
- 密碼錯誤 → 檢查環境變數有沒有打對

## ⚠️ 重要提醒

1. **這支腳本沒有防重複機制**。如果跑兩次,會匯入兩份一模一樣的資料。
   如果不確定跑過沒有,先去畫面上用搜尋功能查一下代表性的品名(例如「迷迭香」)
   確認清單裡有沒有已經存在,再決定要不要執行。

2. **匯入的植物預設「未分區」**(沒有指定溫室分區),因為原始清單沒有這個
   資訊。匯入完成後,建議你到畫面上批次用「移動」功能,把植物分配到實際
   擺放的區域。

3. **鹿角蕨的親緣關係(母株/子代)沒有自動建立**。清單裡有些「側芽」明顯
   是從某株母株分出來的(如「爪哇側芽」),但因為原始清單沒有明確的母株
   對應關係,無法自動連結,匯入後這些側芽會是獨立個體,沒有母株記錄。
   如果你想補上血緣關係,可以匯入完成後手動用「繁殖分盆」功能重新建立
   對應關係(不過這樣會產生新的子代,不是把現有植株連結起來——目前系統
   沒有「事後補血緣關係」的功能,只能重新繁殖或忽略這點)。

4. **價格全部視為已經花費的成本**,匯入後「淨損益」「持有成本」等統計數字
   會立刻反映這 240 株的購入總價。如果你只是想先看清單、還不想影響財務
   統計,請先跟我說,我可以調整成價格全部設 0 的版本。
